# The Meeting That Should Have Been One Line

A submission for the make.fun bounty capturing the single sentence that could have replaced an entire pointless meeting.

### The Line

> "We spent an hour deciding nothing because nobody in this room is allowed to decide anything."

A deadpan distillation of corporate inertia, puncturing the illusion of consensus when decision-making authority is absent.

### Running

To generate the entry:

```bash
python3 main.py
```

The script validates the constraints (1-200 UTF-8 characters, single sentence) and writes the line to `/output/entry.txt`.
